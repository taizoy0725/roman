# Roman

Roman は、かな漢字変換に LLM（大規模言語モデル）を導入した macOS 用の日本語入力ソフト（IME）です。ローマ字を続けて打つだけで、文脈に合った漢字かなまじり文になります。

```
打鍵   nihongonyuuryokuhakawaru
        │
        │  打鍵と同時
        ▼
かな   にほんごにゅうりょくはかわる
        │
        │  打鍵が止まると
        ▼
変換   日本語入力は変わる
```

Roman は、変換キーを押さずに打鍵へ追随して変換が進む「ライブ変換」の一種ですが、打つそばから確定はせず、打鍵の合間にできる間合いをそのまま変換に使います。この打ち方を **Roman タッチ** と呼びます。

Roman の変換は、辞書による候補生成・AI による評価と判定・あなたの学習と一体で、かな漢字の組み合わせを決定します。この方式を **Roman変換** と呼びます（仕組みは[ユーザマニュアル](docs/manual.md#31-roman変換)の §3.1）。

その土台にあるのは、**文節のつながりや文脈が定まれば、仮名と漢字の組み合わせは、IME で候補として選べる組み合わせより遥かに少ない**という見立てです。その少なくなった組み合わせを AI の学習と規則で絞り込めるなら、思考を妨げる候補選びの作業を減らし、多くの場面で無くすことができると考えます。

Roman はさらに AI などによる誤打鍵の訂正も行うことで、入力そのものの誤りも低減させ、さらに円滑な変換を実現します。

なお、変換も学習も AI もあなたの Mac の中だけで動きます。**打った内容がインターネットへ送られることは一切ありません。**（通信するのは、インストール時に言語モデルを取得するときと、設定で「新しい版を月1回確認する」を有効にした場合だけです。）

**まず動きを見る**: [基本操作の概要](docs/quickstart.md)に、打鍵から変換・候補選択・学習・単語登録までを動画(GIF)でまとめています。

## 5つの特徴

- **変換キーいらず** — 打鍵を少し止めると自動で変換され、そのまま打ち続ければ確定も自動で進みます。スペースキーは「他の候補を見たいとき」だけ押します。
- **思考を妨げない** — 打っている途中や打ち直している間に表示が急に変わらず、書く手を止めません。
- **文脈を読んで選ぶ** — 前後の文章を手掛かりに、選ぶべき文言・同音異義語を AI が判断します。
- **使うほど手に馴染む** — あなたが選んだ候補を自動で学習し、次から優先します。打ち間違いの癖も学習し、訂正に反映します。
- **すべて手元で完結** — 変換・学習・AI 推論のすべてがローカル処理です。

## 変換の実績

公開されている評価データ [AJIMEE-Bench](https://github.com/azooKey/AJIMEE-Bench)（日本語Wikipedia入力誤りデータセットから作られた 200 問。前の文がある問題と、ない問題が 100 問ずつ）での実測です。

| 指標 | Roman 1.18 | (参考) Roman 1.17 |
|---|---|---|
| 第1候補が正解 (Acc@1) | **80.5%**（前の文なし 83.0% / 前の文あり 78.0%） | 73.5% |
| 文字誤り率 (CER) | **2.60%** | 4.85% |

読みを入力し、実際に使うときと同じ経路（辞書・AI の採点・文脈での選び直し）を通して、画面に出る表記をそのまま答えとしています。測り方の詳細は[ユーザマニュアル §3.1](docs/manual.md#変換の実績)を参照してください。

## インストール方法

所要時間は 15〜45 分程度です（大半はモデルのダウンロード時間で、回線速度によります。約 4.8 GB を取得します）。上から順に進めてください。

**別途ご用意いただくものはありません。** かな漢字変換に使う AI・言語モデルの実行環境・変換サーバ・Python まで、すべてインストーラに入っています。採点に使う BERT と、文脈で候補を選び直す Qwen の2つのモデルだけは、**インストールが終わったあとに確認のうえ取得します**（実行環境を含め 合計 約 4.8 GB）。

### 1. Roman 本体および言語モデルをインストールする

Roman 本体（パッケージ）をインストールしたあと、続けて Roman が使う言語モデルが取得されます。

#### パッケージ（Roman 本体）のダウンロードとインストール

[リリースページ](../../releases/latest)から最新の pkg をダウンロードし、**ダブルクリック**して、画面の指示に従い Roman をインストールします。入力メソッドをシステムの領域へ入れるため、途中で管理者パスワードを求められます。

Roman 本体のほかに、変換辞書・AI モデル (zenz)・その実行環境 (llama.cpp)・形態素解析器 (kuromoji.js)・Node.js・CPython が一緒に入ります（インストール後 約 390 MB）。**これらを別途ご用意いただく必要はありません。** 一覧は[付録1: インストールされる第三者ソフトウェア](#付録1-インストールされる第三者ソフトウェア)を参照してください。

インストールが終わったら、**「インストールが完了しました」の画面で「閉じる」を押してください。** ここから先の案内は、閉じたあとに一つずつ出ます（途中に割り込まないようにしているためです）。

#### 入力ソースの有効化を許可する

「閉じる」を押すと、Roman が入力ソースとして使えるよう、macOS が確認します。

> **"Roman" が "Roman" を有効にすることを許可しますか?**

**許可**を押してください。これで Roman が入力ソースとして有効になります。

**許可しない**を押した場合、Roman は入力ソースとして有効になりません。あとから システム設定 > キーボード > 入力ソース > ＋ で「日本語 - Roman」を追加できます。

#### 言語モデルの取得（自動）

続いて、Roman は**お使いの環境に何が足りないか**を調べます。ollama をお使いで Qwen を入れている場合、ご自身で BERT の環境（`~/.roman-bert`）を作っている場合、`~/.cache/huggingface` に同じ BERT モデルがある場合は、それらを使います。

**不足が無ければ確認は出ず、そのままインストールの完了の案内へ進みます。** 不足があるときだけ、次の確認が出ます。表示される容量は**不足分だけ**です。

> **言語モデル (Qwen・BERT) をダウンロードします**
> Roman は前後の文脈から表記を選び直すために言語モデル (Qwen) を、候補の採点に BERT を使います。
> 不足しているものを約 4.8 GB ダウンロードします。ダウンロードは初回の一度だけで、以後 Roman が通信することはありません。
> いま取得しますか?
> **NO** / **YES**

**YES** を選ぶと、**不足しているものだけ**を取得します（すでにお持ちのものは改めて取得しません）。その場で取得が始まり、**進み具合を示すウィンドウ**が出ます（下記）。**この確認は一度だけ**で、以後は出ません。

**NO** を選ぶと**取得は行われません**（この確認も以後は出ません）。この状態でも変換は動きますが、辞書だけの変換になり、候補の採点（BERT）と文脈による選び直し（Qwen）は働きません。あとから取得する方法、およびご自身で用意する方法は[付録2: 言語モデルを自身で用意する場合](#付録2-言語モデルを自身で用意する場合)を参照してください。

取得されるものの一覧（提供元・ライセンス・容量）と、BERT・Qwen それぞれの説明は[付録1: インストールされる第三者ソフトウェア](#付録1-インストールされる第三者ソフトウェア)にまとめています。

#### 取得中の進み具合

言語モデルを取得している間は、**進み具合を示す小さなウィンドウ**が出ます（「Qwen (言語モデル) 1.3 / 2.8 GB (45%)」「BERT の環境を用意しています…」のように表示します）。

- **「隠す」を押してもダウンロードは続きます。** 邪魔なときは閉じてかまいません
- **取得が終わるまで、Mac をログインし直さないでください。** ログアウトすると取得が中断します

#### インストールの完了

**言語モデルが揃った時点で**、次の案内が出ます。**OK** を押せば手順 1 は終わりです。

> **Roman のインストールが完了しました。**
> 言語モデルの取得が終わり、候補の採点 (BERT) と文脈による選び直し (Qwen) が有効になりました。
>
> このあと次により Roman が有効になります
> (1) Mac からログアウト後ログインする
> (2) メニューバー右上の入力メニューから Roman を選択する

言語モデルがすでに揃っていた場合は、2行目が無い（(1)(2) だけの）案内が出ます。**NO** を選んだ場合は「言語モデルは取得しませんでした。あとから取得できます」に変わります。取得に失敗した場合もその旨をお知らせします（**Roman 設定…** の「**言語モデルを取得…**」からやり直せます／[付録2](#付録2-言語モデルを自身で用意する場合)）。

先ほどの確認で**許可しない**を選んでいた場合は、案内の手順が3つになり、先頭に「システム設定 > キーボード > 入力ソース > ＋ から『日本語 - Roman』を追加する」が入ります。

### 2. ログインし直してから、入力ソースを選択する

**入力ソースへの追加はインストーラが済ませています。** 反映にはログインし直しが必要です。

1. **一度 Mac からログアウトし、ログインし直してください**（言語モデルの取得中は避けてください。取得が中断します）
2. 画面上部のメニューバー右側にある**入力メニュー**（いま選ばれている入力ソースのアイコンが出ています）から **Roman** を選択します。一覧に **Roman** が出ないときは、**システム設定 > キーボード > 入力ソース > 編集** を開き、**＋** から「日本語」の中の **Roman** を追加してください
3. 最初に入力するとき、**アクセシビリティ**の許可を求められます。**システム設定 > プライバシーとセキュリティ > アクセシビリティ** で Roman を有効にしてください。変換中の Esc キーをアプリから保護する（下線が壊れるのを防ぐ）ために使います。許可しなくても入力はできますが、一部アプリ（Electron 系）で Esc の挙動が不安定になります。

### 3. 動作を確認する

テキスト編集などで Roman に切り替え、`nihongo` と打って「日本語」と表示されれば完了です。

うまくいかないときは、次のコマンドで状態を確かめられます。

```bash
curl -s http://127.0.0.1:8765/api/status
```

| 表示 | 意味 |
|---|---|
| 応答がない | 変換サーバが動いていません。手順 1 をやり直してください |
| `"zenz":false` | かな漢字変換の AI が動いていません。手順 1 をやり直してください |
| `"bert":false` | 採点用の Python 環境が見つかりません。[付録1](#付録1-インストールされる第三者ソフトウェア)の（1）BERT、または[付録2](#付録2-言語モデルを自身で用意する場合)を確認してください |
| `"backend":"mock"` | 汎用の言語モデルがありません。[付録1](#付録1-インストールされる第三者ソフトウェア)の（2）Qwen、または[付録2](#付録2-言語モデルを自身で用意する場合)を確認してください |

### 4. Roman を使用する

インストールは以上です。操作方法・設定・困ったときの対処は[ユーザマニュアル](docs/manual.md)にまとめています。

| No | 知りたいこと | 参照先 |
|---|---|---|
| 0 | まず一通り動きを見る（GIF） | [基本操作の概要](docs/quickstart.md) |
| 1 | 打ち方と変換の進み方（Roman タッチ） | [§3.2 基本の入力](docs/manual.md#32-基本の入力) |
| 2 | 他の候補を見る・選ぶ | [§3.4 候補ウィンドウ](docs/manual.md#34-候補ウィンドウ) |
| 3 | 学習のしくみと消し方 | [§3.5 学習](docs/manual.md#35-学習) |
| 4 | 変換の間合い（タメ）などの調整 | [§4 設定](docs/manual.md#4-設定) |
| 5 | 変換されない・Esc が効かない | [§6 トラブルシューティング](docs/manual.md#6-トラブルシューティング) |

## 付録1: インストールされる第三者ソフトウェア

Roman が使う第三者のソフトウェアは、**pkg に同梱して一緒に入るもの**（下記 1）と、**インストールの最後に公式配布元から取得するもの**（下記 2）に分かれます。いずれもご自身で用意する必要はありません。

### 1. 同梱される第三者ソフトウェア

pkg をインストールすると、Roman 本体のほかに次のものが一緒に入ります（インストール後 約 390 MB）。

| No | 名称 | 概要 | 版 | 役割 |
|---|---|---|---|---|
| 1 | 変換辞書・組織名リスト | mozc の OSS 辞書と Wikidata に由来する語彙データ | — | 語彙と接続コストで変換候補を組み立てる |
| 2 | zenz-v3-small | かな漢字変換に特化した小型の AI モデル | — | 辞書で覆えない読み（新語など）を、読みに忠実に変換する |
| 3 | llama.cpp | AI モデルを Mac 上で動かすための実行環境 | b9960 | zenz を動かす |
| 4 | kuromoji.js | 日本語の形態素解析器 | 0.1.2 | 独立した3つの用途に使う。(1)候補の絞り込み — zenz が作った候補から、打鍵した読みと違うものを捨てる (2)言い換えの単位づくり — 変換後の文を文節に区切り、文節ごとの言い換え候補を作る (3)学習の選別 — 自動学習で名詞だけを拾い、活用形が辞書に紛れるのを防ぐ |
| 5 | Node.js | JavaScript の実行環境 | v22.23.2 | 上記すべてを載せた変換サーバを動かす |
| 6 | CPython | Python の実行環境 | 3.12.13 | 下記で取得する BERT を動かす。Python を別途入れる必要をなくすために同梱している |

※ **mozc** は Google が公開しているオープンソースの日本語入力ソフトです。Roman が使っているのはその辞書データ（語彙と、語と語のつながりやすさを表す接続コスト）だけで、変換の仕組みそのものは Roman の書き下ろしです。

適用されるライセンスは[利用条件](#利用条件)にまとめています。

### 2. 取得される第三者ソフトウェア（言語モデル）

これらは配布物には含まれておらず、**お使いのマシンへ直接ダウンロード**されます。BERT と Python パッケージはそれぞれの公式配布元から、Qwen は Qwen 公式のモデルを本プロジェクトが GGUF 形式に変換・4ビット量子化したものを本プロジェクトの Release から取得します（Apache 2.0・改変あり）。取得先は次のとおりです。

| No | 名称 | 概要 | 提供元 | ライセンス | 容量 |
|---|---|---|---|---|---|
| 1 | bert-base-japanese-v3 | 日本語 BERT のモデル | 東北大学 自然言語処理研究室（Hugging Face） | Apache 2.0 | 約 0.9 GB |
| 2 | PyTorch・transformers・fugashi・unidic-lite | BERT を動かすための Python パッケージ | PyPI | BSD-3 / Apache 2.0 ほか | 約 1.1 GB |
| 3 | Qwen3.5-4B (GGUF・4ビット量子化) | 汎用の言語モデル | 元モデル: Alibaba Cloud / Qwen（Hugging Face）。変換・配布: 本プロジェクトの Release | Apache 2.0（改変あり） | 約 2.8 GB |

合計 約 4.8 GB をダウンロードし、`~/Library/Application Support/Roman/state/` 配下に置きます。Roman をアンインストールすれば一緒に消えます。

#### （1）BERT

候補の自然さを採点するのに使います。Python の実行環境は Roman に同梱しているので、Python を別途入れる必要はありません。

Roman が用意するもの（`~/Library/Application Support/Roman/state/bert-venv/`）:

- PyTorch・transformers・fugashi・unidic-lite（約 1.1 GB）
- BERT モデル tohoku-nlp/bert-base-japanese-v3（約 0.9 GB、Apache 2.0）

Roman は同梱の Python だけを使い、お使いのマシンの Python 環境（Homebrew・pyenv・`PYTHONHOME` などの設定）には影響を受けません。逆に、Roman が入れるものがお使いの Python 環境を汚すこともありません。

#### （2）Qwen

前後の文脈から候補を選び直したり、打ち間違いを推し量ったりするのに使います。Roman はこのモデルを**同梱の推論エンジンで動かす**ので、ollama などを別に用意する必要はありません。

取得したモデルの置き場所は `~/Library/Application Support/Roman/state/models/` です。

##### モデルを使わない場合

メモリが 12 GB 未満のマシンでは、モデルを取得していても常駐させません。この場合も**変換は動きます** — 辞書ラティスと BERT、zenz で変換し、文脈による選び直しだけが働かない状態になります。

## 付録2: 言語モデルを自身で用意する場合

インストール時の確認で **NO** を選んだ場合や、取得が途中で失敗した場合、すでに ollama や BERT の環境をお持ちの場合は、次のいずれかで用意できます。取得の対象と容量は[付録1](#付録1-インストールされる第三者ソフトウェア)を参照してください。

### A. あとから Roman に取得させる

入力メニューの **Roman 設定…** を開き、「**言語モデルを取得…**」を押します。**不足しているものだけ**を取得します（Qwen だけが無ければ Qwen だけ、BERT の環境だけが無ければそれだけ）。

このボタンは**不足があるときだけ表示されます**。すべて揃っている場合は現れません。取得中は「取得の進み具合…」、失敗したあとは「言語モデルの取得をやり直す…」に変わります。

### B. ご自身で用意する

Roman は、お使いの環境に既にあるものを見つけたらそちらを優先し、二重には取得しません。

#### BERT（候補の採点）

| No | 用意するもの | 置き場所 | 備考 |
|---|---|---|---|
| 1 | Python 環境（PyTorch・transformers・fugashi・unidic-lite） | `~/.roman-bert/venv` | ここに venv があれば**そちらが使われ、ダウンロードは行いません** |
| 2 | BERT モデル tohoku-nlp/bert-base-japanese-v3 | `~/.cache/huggingface` | 同じモデルが既にあればそれを使います |

Roman が自分で用意する場合の置き場所は `~/Library/Application Support/Roman/state/bert-venv/` です。同梱の Python だけを使うため、お使いのマシンの Python 環境には影響しません。

#### Qwen（文脈による選び直し）

すでに **ollama** をお使いなら、そちらが優先されます（Roman は動いている ollama を見つけると、そのまま使います）。

```bash
ollama pull qwen3.5:4b
```

GGUF を手元に置いて使うこともできます。`~/Library/Application Support/Roman/state/models/` に [Release](https://github.com/taizoy0725/roman/releases/tag/models-qwen3.5-4b) の2ファイル（分割ファイルはそのまま）を置けば、Roman が起動時に見つけます。

## 付録3: アンインストール

Roman をアンインストールするには、次のコマンドをターミナルから実行ください。

```bash
launchctl bootout gui/$(id -u)/com.mobazou.roman.server; rm -f ~/Library/LaunchAgents/com.mobazou.roman.server.plist; rm -rf ~/Library/"Application Support"/Roman; sudo rm -rf "/Library/Input Methods/Roman.app"
```

入力ソースからの削除は、システム設定 > キーボード > 入力ソース > 編集 で行います。

**Roman が入れたものはすべて上のコマンドで消えます** — 言語モデル（BERT・Qwen、約 5.6 GB）も Python の実行環境も `~/Library/Application Support/Roman/` の下にあるためです。学習データも同時に消えるので、残したい場合は先に `state/` フォルダをコピーしてください（[ユーザマニュアル §3.5 学習データの保存場所](docs/manual.md#学習データの保存場所)）。

**ご自身で別途入れたものだけは残ります。** 他の用途にも使うものなので、必要に応じて個別に消してください（Roman はこれらを消しません）。

| No | 残るもの | 消し方 |
|---|---|---|
| 1 | ご自身で作った BERT の Python 環境 | `rm -rf ~/.roman-bert` |
| 2 | ご自身で取得した BERT モデル | `rm -rf ~/.cache/huggingface/hub/models--tohoku-nlp--bert-base-japanese-v3` ※ |
| 3 | ollama で入れた Qwen | `ollama rm qwen2.5:7b-instruct` ※ |
| 4 | ollama 本体 | `/Applications` の Ollama.app を削除 |

※ No.2 の `~/.cache/huggingface` と No.3 の `~/.ollama` には、Roman 以外で取得したモデルを入れた場合、それらも同じ場所に入っています。フォルダごと消さず、上表のとおり対象を選んで消してください。
