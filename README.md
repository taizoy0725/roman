# Roman

Roman は、かな漢字変換に LLM（大規模言語モデル）を導入した macOS 用の日本語入力ソフト（IME）です。ローマ字を続けて打つだけで、文脈に合った漢字かなまじり文になります。

```
打鍵   nihongonyuuryokuhakawaru
        │
        │  打鍵と同時
        ▼
かな   にほんごにゅうりょくはかわる
        │
        │  打鍵が止まると
        ▼
変換   日本語入力は変わる
```

Roman は、変換キーを押さずに打鍵へ追随して変換が進む「ライブ変換」の一種ですが、打つそばから確定はせず、打鍵の合間にできる間合いをそのまま変換に使います。この打ち方を **Roman タッチ** と呼びます。

Roman の変換は、辞書による候補生成・AI による評価と判定・あなたの学習と一体で、かな漢字の組み合わせを決定します。この方式を **Roman変換** と呼びます（仕組みは[ユーザマニュアル](docs/manual.md#1-roman変換)の §1）。

その土台にあるのは、**文節のつながりや文脈が定まれば、仮名と漢字の組み合わせは、IME で候補として選べる組み合わせより遥かに少ない**という見立てです。その少なくなった組み合わせを AI の学習と規則で絞り込めるなら、思考を妨げる候補選びの作業を減らし、多くの場面で無くすことができると考えます。

なお、変換も学習も AI もあなたの Mac の中だけで動きます。**打った内容がインターネットへ送られることは一切ありません。**

## 5つの特徴

- **変換キーいらず** — 打鍵を少し止めると自動で変換され、そのまま打ち続ければ確定も自動で進みます。スペースキーは「他の候補を見たいとき」だけ押します。
- **思考を妨げない** — 打っている途中や打ち直している間に表示が急に変わらず、書く手を止めません。
- **文脈を読んで選ぶ** — 前後の文章を手掛かりに、選ぶべき文言・同音異義語を AI が判断します。
- **使うほど手に馴染む** — あなたが選んだ候補を自動で学習し、次から優先します。打ち間違いの癖も学習し、訂正に反映します。
- **すべて手元で完結** — 変換・学習・AI 推論のすべてがローカル処理です。

## インストール方法

所要時間はダウンロードを含めて 30〜60 分程度です。上から順に進めてください。

かな漢字変換に使う AI とその実行環境、変換サーバとその実行環境は、インストーラに入っています。別途ご用意いただくのは、候補の採点に使う言語モデルと、候補の見直しに使う汎用の言語モデルの2つだけで、どちらも手順 2 で入れます。

### 1. パッケージをインストールする

[リリースページ](../../releases/latest)から `Roman-1.0.pkg` をダウンロードし、開いて画面の指示に従い Roman をインストールします。入力メソッドをシステムの領域へ入れるため、途中で管理者パスワードを求められます。

Roman 本体のほかに、次の第三者ソフトウェアが一緒に入ります（合計 約 320 MB）。これらを別途ご用意いただく必要はありません。

| No | 名称 | 概要 | 版 | 役割 |
|---|---|---|---|---|
| 1 | 変換辞書・組織名リスト | mozc の OSS 辞書と Wikidata に由来する語彙データ | — | 語彙と接続コストで変換候補を組み立てる |
| 2 | zenz-v3-small | かな漢字変換に特化した小型の AI モデル | — | 辞書で覆えない読み（新語など）を、読みに忠実に変換する |
| 3 | llama.cpp | AI モデルを Mac 上で動かすための実行環境 | b9960 | zenz を動かす |
| 4 | kuromoji.js | 日本語の形態素解析器 | 0.1.2 | 独立した3つの用途に使う。①候補の絞り込み — zenz が作った候補から、打鍵した読みと違うものを捨てる ②言い換えの単位づくり — 変換後の文を文節に区切り、文節ごとの言い換え候補を作る ③学習の選別 — 自動学習で名詞だけを拾い、活用形が辞書に紛れるのを防ぐ |
| 5 | Node.js | JavaScript の実行環境 | v22.23.2 | 上記すべてを載せた変換サーバを動かす |

※ **mozc** は Google が公開しているオープンソースの日本語入力ソフトです。Roman が使っているのはその辞書データ（語彙と、語と語のつながりやすさを表す接続コスト）だけで、変換の仕組みそのものは Roman の書き下ろしです。

適用されるライセンスは[利用条件](#利用条件)にまとめています。

### 2. 言語モデルをインストールする

次の2つの言語モデルをインストールします。

#### （1）採点用の BERT

Roman は候補の自然さを測るのに **BERT**（東北大の日本語モデル）を使います。同じ読みに対する複数の候補のうち、日本語として収まりの良いものを見分ける役目です。これは Python で動くため、Python を入れたうえで、独立した Python 環境に BERT を実装します（約 1.1 GB）。

**ア）Python をインストールする**

[python.org](https://www.python.org/downloads/macos/) から **3.14** の macOS 用インストーラ（`.pkg`）をダウンロードし、開いて画面の指示に従いインストールします。

**イ）独立した Python 環境を作る**

他の用途と混ざらないよう、Roman 専用の環境を作ります。

```bash
python3.14 -m venv ~/.roman-bert/venv && ~/.roman-bert/venv/bin/pip install torch==2.13.0 transformers==5.14.1 fugashi==1.5.2 unidic-lite==1.0.8
```

`~/.roman-bert/venv` という**置き場所は変えられません。** 「見つかりません」と出て入らない場合は、`==` とそれに続く数字をすべて外して実行してください（動作確認済みの組み合わせからは外れます）。

**ウ）BERT を取得する**

作った環境へ BERT 本体（約 0.9 GB）を入れます。回線によっては数分かかります。

```bash
~/.roman-bert/venv/bin/python3 -c "import transformers; transformers.logging.set_verbosity_error(); from transformers import AutoTokenizer, AutoModelForMaskedLM; m='tohoku-nlp/bert-base-japanese-v3'; AutoTokenizer.from_pretrained(m); AutoModelForMaskedLM.from_pretrained(m); print('BERT ready')"
```

最後に `BERT ready` と出れば完了です。**起動する必要はありません。** Roman が必要になった時点で自動で立ち上げ、落ちていれば起動し直します。

**この手順を飛ばすと、初回の変換で採点が効きません。** Roman は BERT の起動を20秒しか待たないため、その場でのダウンロードは間に合わず、`"bert":false` のまま候補の並びが辞書の統計だけで決まる状態が続きます。

#### （2）汎用の qwen2.5

Roman は、前後の文脈から候補を選び直したり、打ち間違いを推し量ったりするのに、文章全般を扱う言語モデル（**qwen2.5**）を使います。これを動かすのが **ollama** です。

**ア）ollama をインストールする**

[ollama.com](https://ollama.com/download/mac) から Mac 版をダウンロードします。圧縮されている場合は展開し、出てきた **Ollama.app** を「アプリケーション」フォルダへ移してから、**一度起動してください**。

次のように版が返れば入っています。

```bash
curl -s http://127.0.0.1:11434/api/version
```

```
{"version":"0.31.1"}
```

**イ）qwen2.5 を取得する**

約 4.7 GB あり、回線によっては 10〜30 分かかります。

```bash
ollama pull qwen2.5:7b-instruct
```

メモリ 16 GB の環境では、こちらを使ってください。

```bash
ollama pull qwen2.5:3b-instruct
```

### 3. 入力ソースに追加する

1. **システム設定 > キーボード > 入力ソース > 編集** を開き、**＋** から「日本語」の中の **Roman** を追加します。一覧に出ないときは一度ログインし直してください。
2. 画面上部のメニューバー右側にある**入力メニュー**（いま選ばれている入力ソースのアイコンが出ています）から **Roman** を選択します（キーボードでも切り替えられます。下表）。
3. 最初に入力するとき、**アクセシビリティ**の許可を求められます。**システム設定 > プライバシーとセキュリティ > アクセシビリティ** で Roman を有効にしてください。変換中の Esc キーをアプリから保護する（下線が壊れるのを防ぐ）ために使います。許可しなくても入力はできますが、一部アプリ（Electron 系）で Esc の挙動が不安定になります。

入力ソースはキーボードでも切り替えられます。

| キー | 動作 |
|---|---|
| `Control` + `Space` | 前の入力ソースへ（直前に使っていたものとの往復） |
| `Control` + `Option` + `Space` | 次の入力ソースへ（登録した入力ソースを順に巡回） |

割り当ては **システム設定 > キーボード > キーボードショートカット > 入力ソース** で確認・変更できます。

### 4. 動作を確認する

テキスト編集などで Roman に切り替え、`nihongo` と打って「日本語」と表示されれば完了です。

うまくいかないときは、次のコマンドで状態を確かめられます。

```bash
curl -s http://127.0.0.1:8765/api/status
```

| 表示 | 意味 |
|---|---|
| 応答がない | 変換サーバが動いていません。手順 1 をやり直してください |
| `"zenz":false` | かな漢字変換の AI が動いていません。手順 1 をやり直してください |
| `"bert":false` | 採点用の Python 環境が見つかりません。手順 2（1）を確認してください |
| `"backend":"mock"` | 汎用の言語モデルがありません。手順 2（2）を確認してください |

操作方法は[ユーザマニュアル](docs/manual.md)を参照してください。

パスワード欄などのセキュア入力では IME はバイパスされ、半角英数がそのまま入ります。

### アンインストール

```bash
launchctl bootout gui/$(id -u)/com.mobazou.roman.server; rm -f ~/Library/LaunchAgents/com.mobazou.roman.server.plist; rm -rf ~/Library/"Application Support"/Roman; sudo rm -rf "/Library/Input Methods/Roman.app"
```

入力ソースからの削除は、システム設定 > キーボード > 入力ソース > 編集 で行います。

上のコマンドで消えるのは Roman 本体だけです。**手順 2 でご自身の Mac に入れたものは残ります。** 他の用途にも使うものなので、必要に応じて個別に消してください。

| 残るもの | 消し方 |
|---|---|
| BERT 用の Python 環境（約 1.1 GB） | `rm -rf ~/.roman-bert` |
| BERT のモデル本体（約 0.9 GB） | `rm -rf ~/.cache/huggingface/hub/models--tohoku-nlp--bert-base-japanese-v3` |
| Qwen2.5 のモデル（約 4.7 GB） | `ollama rm qwen2.5:7b-instruct` |
| ollama 本体 | `/Applications` の Ollama.app を削除 |
| Python 本体 | 他でも使うため、通常は残したままで構いません |

`~/.cache/huggingface` と `~/.ollama` には、Roman 以外で取得したモデルも入ります。フォルダごと消さず、上表のとおり対象を選んで消してください。
